Product UI · Web application

Sensor monitoring console

A console for a building sensor network — smoke, PM2.5, temperature, humidity and combined units across many sites. The home view answers the only question an operator has on opening it: what is wrong and where. Counts by sensor type across the top, a map with the sites plotted, connection status per type as a ratio rather than a percentage, and today's alarms as a list you can read without clicking.

Behind it sits the unglamorous half: device, customer, user and user-group management, and an alert-rule editor, all built on one table-and-form pattern so that learning one screen teaches you the rest.

Product UI · Mobile

Dealer reporting app

A phone tool for car dealer staff and regional managers to file and read the numbers that run a dealership: monthly retail forecasts by model, gross margin per vehicle, competitor pricing, aged inventory, and point-of-sale material.

Almost every screen is either a table you read or a table you fill in, on a phone, by someone who does it monthly and does not want to think about it. So the layout stays the same throughout — model on the left, figure on the right, one primary action at the bottom — and the design work went into the states around it: what an empty period looks like, what an editable cell looks like next to a fixed one, and where the warning goes when a number needs a caveat.

Product UI · Voice interface

Voice-controlled home screen

A screen for a voice assistant, where the display is the assistant's second channel rather than its main one. Rooms sit on a ring around the microphone, scenes are isometric places rather than lists of switches, and a waveform along the bottom edge shows the system listening without a modal taking over the screen.

E-commerce

ilk London

A men's grooming shop built on a hard editorial grid: heavy condensed type, a lot of white, one yellow that only ever means "buy". Product filtering is set as a row of line icons — skin type, routine step, product type — so a browse can be narrowed without opening a panel, and editorial blocks are cut into the product grid at full width to break the catalogue rhythm.

Industrial group website

A corporate site for an oil-services and equipment group, with the problem most corporate sites have: several audiences, one homepage. The structure separates them — technology and services, group profile, R&D, markets, recruitment — and a diagram of the group's subsidiary structure does the work that three paragraphs of company history usually fails to do. Designed for desktop and phone.
