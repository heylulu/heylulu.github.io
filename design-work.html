Product UI · Web and mobile

Cadillac dealer platform

A set of tools that head office and its dealers use on the same data: quarterly sales targets, weekly and monthly reports, aged-inventory trading, showroom-material audits, and dealer performance. Web for the desk work, phone for the work that happens standing up in a showroom.

The structural problem is that head office and a dealer are looking at the same numbers from opposite sides. Head office issues a target, verifies what comes back, and confirms it; the dealer views it, submits against it, and keeps its own history. Rather than build two products, the platform keeps one layout and swaps the tab strip and the permissions — so the screen a regional manager talks a dealer through is recognizably the screen the dealer is looking at.

Product UI · Web application

Sensor monitoring console

A console for a building sensor network — smoke, PM2.5, temperature, humidity and combined units across many sites. The home view answers the only question an operator has on opening it: what is wrong and where. Counts by sensor type across the top, a map with the sites plotted, connection status per type as a ratio rather than a percentage, and today's alarms as a list you can read without clicking.

Behind it sits the unglamorous half: device, customer, user and user-group management, and an alert-rule editor, all built on one table-and-form pattern so that learning one screen teaches you the rest.

E-commerce · Three rounds

Yulan Home

A shop for wallpaper and home furnishing, where nobody arrives knowing the product code they want. It went through three rounds, and the rounds are the interesting part: the first put two genuinely different answers on the table, and the site that shipped is neither of them.

Web Retail Iteration Catalogue structure

What survives all three rounds is the room-based entry — living room, dining room, bedroom, study, nursery, entryway — because it is the only way in that matches how someone actually shops for wallpaper. What changes is how much the page argues: the illustrated round barely sells, the second round sells explicitly, and the final one puts the catalogue back within one click while keeping the rooms.
